Who operates Nexera

Nexera AI is distributed by the publisher identified on the app's store listing. The app does not require a Nexera account. This project does not provide a Nexera-operated hosted Python Agent service.

Information stored on your device

Project/workspace information and app settings are stored in local app storage. Android provider API keys are encrypted using Android Keystore-backed storage. Windows uses Electron's operating-system secure storage. Browser-only use does not provide the same native credential storage and does not persist BYOK keys.

The optional Python Agent backend URL is saved in app settings. Its bearer token is held in the active app session and must be entered again after restarting.

Information sent to other services

When you send a message, your prompt and relevant conversation context are sent to the AI provider selected in the app. Providers may include Kilo Gateway, LLMFaucet, OVH AI Endpoints, LLM7, UncloseAI, Puter, OpenRouter, DeepSeek, Zhipu/GLM, or Alibaba Cloud DashScope/Qwen. Each provider processes requests under its own terms and privacy policy. Nexera does not control their retention or model-training practices.

If you use web search, the search query is sent to DuckDuckGo.

If you select the optional Python Agent route, the current project files and agent request are sent to the backend URL you configure. That backend operator controls access, workspace retention, logs, backups, and the OpenRouter account used by the service. Only connect to a backend you trust.

Information sharing and sale

Nexera does not operate an advertising profile or sell user information. Information is sent to third-party services when you choose a feature or provider that requires it, as described above. The publisher must review all third-party SDKs and provider terms before release.

Data retention and deletion

Project data stored locally can generally be removed by deleting projects or clearing app storage/uninstalling the app. Data already sent to an AI provider, search service, or user-configured Python backend is subject to that service's retention and deletion policies.

Security

Nexera uses native secure storage for saved provider credentials on Android and Windows. Network requests to configured AI providers use HTTPS. The optional Python Agent backend should only be used with a trusted HTTPS endpoint. No internet-connected service can guarantee absolute security.

Children's privacy

Nexera is not designed to collect personal information from children. Do not submit sensitive personal information, passwords, private keys, or confidential documents to public AI gateways.

Changes and contact

This notice may be updated when app features, providers, or data practices change. For privacy questions, contact the publisher at the address listed above.
