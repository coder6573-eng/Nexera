# Nexera V1–V10 development passes

This log records the ten implementation passes for the current Nexera rebuild. A pass is considered shipped only after its regression checks and platform build complete successfully.

| Pass | Scope | Verification target |
| --- | --- | --- |

## Release gate

- [ ] npm test passes on the final commit.
- [ ] Android Gradle build succeeds and the APK artifact is uploaded.
- [ ] Windows Electron packaging succeeds and the EXE artifact is uploaded.
- [ ] Native provider, search, preview and export flows are checked on-device / desktop before describing the release as fully verified.

Puter is the keyless AI route and requires a valid HTTPS/localhost origin plus user authentication when prompted. The Android WebView uses WebViewAssetLoader; Electron serves the bundled UI on a loopback HTTP origin.\n\nThe workspace terminal is deliberately a restricted app-workspace command runner, not a general-purpose system shell. The current workspace persists inside Nexera; direct arbitrary local-folder access is not part of this build. BYOK credentials are kept in Android Keystore or Electron safeStorage and are never written to localStorage.\n\nThe ten pass labels are a quality checklist, not ten independently released builds. Each pass must pass its tests and both platform builds before it is considered shipped.
